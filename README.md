# Java OOP Mastery

> **Understand Java. Master OOP. Think like an engineer.**

A deep, engineering-focused journey into **Java and Object-Oriented Programming**, built around understanding how software works rather than memorizing syntax.

This repository explores Java from the ground up — starting with programming fundamentals and gradually moving into the object model, OOP principles, JVM architecture, bytecode execution, and professional software design.

## What This Repository Explores

- Java language fundamentals
- Variables, types, operators, control flow, methods, and arrays
- Classes and objects
- Encapsulation
- Abstraction
- Inheritance
- Polymorphism
- Composition
- Interfaces
- Exception handling
- Java compilation and bytecode
- JVM architecture
- Class loading
- Execution engine
- JIT compilation
- Garbage collection
- Object-oriented design and reasoning

## Learning Philosophy

This is not a syntax-collection repository.

The focus is:

**Understand → Reason → Code → Test → Break → Debug → Design → Explain → Teach**

Every important concept is approached through:

**WHAT → WHY → HOW → INTERNALS → CODE → RUN → TEST → DEBUG → COMPARE → REAL-WORLD APPLICATION**

## Goal

The goal is not simply to "learn Java."

The goal is to develop the ability to:

- reason about object-oriented systems
- design maintainable software
- understand how Java executes
- recognize coupling and poor abstractions
- choose composition or inheritance deliberately
- use polymorphism effectively
- debug behavior at both language and runtime levels
- explain technical decisions clearly

Java is being used as a vehicle for developing **strong object-oriented programming and software engineering fundamentals**.
